# 💸 쓴맛 (SseunMat)
> **"돈을 쓴 뒤에 남는 것은 무엇일까?"**  
> 쓴맛은 단순한 지출 관리를 넘어, 소비를 통해 얻은 행복과 가치를 기록하는 **감성 소비 일기 서비스**입니다.

2026 GURU2 Android 3조 '잘썼조'의 '쓴맛' 프로젝트 레포지토리입니다.

---

## 💡 서비스 소개 & 기획 배경

### 📖 기획 배경
기존의 가계부 서비스는 단순히 '얼마를 썼는지' 숫자를 관리하는 데 초점이 맞춰져 있습니다. 하지만 같은 금액을 지출하더라도 어떤 소비는 오래 기억되는 행복이 되고, 어떤 소비는 후회로 남기도 합니다.  
**'쓴맛'**은 지출 금액보다 **소비를 통해 얻은 가치와 감정을 기록**하여, 사용자가 자신의 소비 패턴을 새로운 관점에서 돌아볼 수 있도록 기획되었습니다.

### ✨ 주요 특징
* **AI 영수증 자동 스캔:** 실물/모바일 영수증을 촬영하면 상호명, 결제 날짜, 금액을 AI가 자동으로 인식합니다.
* **영수증 뒤집기 인터랙션:** 앞면(결제 정보)과 뒷면(소비 가치 및 일기)을 뒤집는 카드로직을 통해 '얼마를 썼는지'가 아닌 **'무엇을 얻었는지'**를 시각적으로 경험합니다.
* **가치 아카이브:** 소비를 금액이 아닌 7가지 가치(위로, 휴식, 관계, 추억, 배움, 영감, 마음 표현) 중심으로 분류하여 당월 지출 패턴과 행복도를 시각화합니다.

## 📱 핵심 기능 (MVP)

* [x] **01. 회원가입 및 로그인**
    * Firebase Authentication 기반의 이메일 계정 인증 및 자동 로그인 지원
* [x] **02. 영수증 인식 및 자동 등록 (Gemini AI)**
    * 실물/모바일 영수증 촬영 시 AI가 상호명, 결제 날짜, 금액을 추출하여 자동 입력
    * 인식된 정보의 사용자 수동 수정 지원
* [x] **03. 가치 지출 일기 작성**
    * 소비의 가치 선택 (위로 / 휴식 / 관계 / 추억 / 배움 / 영감 / 마음 표현)
    * 만족도 별점(1~5점), 기부 소비 여부, 짧은 글(100자 제한) 기록
* [x] **04. 영수증 카드 뒤집기 인터랙션 (홈 피드)**
    * 앞면(결제 정보) / 뒷면(가치 및 일기) 180도 뒤집기 애니메이션 제공
* [x] **05. 당월 가치 아카이브 (통계 및 분석)**
    * 당월의 총 지출액 및 가장 많이 얻은 가치 시각화
    * 가치별 지출 금액 및 모아보기 필터링 기능
* [x] **06. 마이페이지**
    * 사용자 프로필 확인 및 로그아웃/계정 관리
